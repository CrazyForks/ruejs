# Phase 1: 删除 runtime-vapor 的 compat 特性壳

Plan 11 已经把 runtime-vapor 的 compat 边界压成了显式模块，但 `compat feature` 本身还没有删除。Plan 12 的第一阶段要做的不是再收边界，而是直接把这层 feature 外壳拆掉，让 [packages/runtime-vapor/src](../../packages/runtime-vapor/src) 成为单模内核。

当前状态：该阶段已经完成。runtime-vapor 现已切成单模 vapor-only 内核，后续工作应转入 Phase 2 的 JS runtime 公开契约清理。

## 当前信号

- [packages/runtime-vapor/src](../../packages/runtime-vapor/src) 下已不存在 `#[cfg(feature = "compat")]` 控制的 runtime 主路径；[packages/runtime-vapor/Cargo.toml](../../packages/runtime-vapor/Cargo.toml) 里的 `compat` feature 也已删除。
- [packages/runtime-vapor/src/runtime/types.rs](../../packages/runtime-vapor/src/runtime/types.rs)、[packages/runtime-vapor/src/runtime/types/mounted.rs](../../packages/runtime-vapor/src/runtime/types/mounted.rs)、[packages/runtime-vapor/src/runtime/real_dom/mod.rs](../../packages/runtime-vapor/src/runtime/real_dom/mod.rs)、[packages/runtime-vapor/src/runtime/render_patch/mod.rs](../../packages/runtime-vapor/src/runtime/render_patch/mod.rs) 已经完成单模化，compat-only mounted snapshot / patch / lifecycle / real-dom dispatch 已删除。
- [packages/runtime-vapor/src/runtime/bridge/create_element.rs](../../packages/runtime-vapor/src/runtime/bridge/create_element.rs)、[packages/runtime-vapor/src/runtime/bridge/input.rs](../../packages/runtime-vapor/src/runtime/bridge/input.rs)、[packages/runtime-vapor/src/runtime/vnode_helpers.rs](../../packages/runtime-vapor/src/runtime/vnode_helpers.rs)、[packages/runtime-vapor/src/runtime/real_dom/convert.rs](../../packages/runtime-vapor/src/runtime/real_dom/convert.rs) 已删除 createElement 公开 API、compat child flatten、raw vnode-like object / raw array / raw function component / legacy wrapper 解析链。
- [packages/runtime-vapor/tests](../../packages/runtime-vapor/tests) 下 compat 专属测试文件已删空或改写为单模测试；默认命令 `wasm-pack test --node --features dev --features log` 通过，且 [packages/runtime-vapor/pkg-node](../../packages/runtime-vapor/pkg-node) 已重建，不再导出 `createElement`。

## 目标

1. 删除 `MountInputType` 与 mounted snapshot 里只服务于 compat feature 的分支。
2. 删除 raw vnode-like object / raw array / raw function component / raw element 旧输入路径。
3. 冻结 vapor-only 默认 transport / mounted snapshot 契约，不再把 compat createElement / mount-handle protocol 与默认主路径耦合在一起。
4. 删除 compat patch root、compat lifecycle overlay、compat real-dom dispatch。
5. 删除 runtime-vapor 的 compat 专属测试与 `no-default-features` 对照口径中的“compat 对照项”，并把默认 Cargo feature 也切到单模口径。

## 工作内容

1. 类型层删壳。
   直接删除 `MountInputType::Fragment`、`MountInputType::Element`、`MountedState::Compat`、`MountedPatchSubtreeType::Compat`、`MountLifecycleKind::Compat` 以及 [packages/runtime-vapor/src/runtime/types/compat_state.rs](../../packages/runtime-vapor/src/runtime/types/compat_state.rs)、[packages/runtime-vapor/src/runtime/types/compat_lifecycle.rs](../../packages/runtime-vapor/src/runtime/types/compat_lifecycle.rs)、[packages/runtime-vapor/src/runtime/types/compat_patch_root.rs](../../packages/runtime-vapor/src/runtime/types/compat_patch_root.rs)、[packages/runtime-vapor/src/runtime/types/compat_subtree.rs](../../packages/runtime-vapor/src/runtime/types/compat_subtree.rs) 这一整层 overlay，并同步收紧 [packages/runtime-vapor/src/runtime/types/mounted.rs](../../packages/runtime-vapor/src/runtime/types/mounted.rs) 的 mounted snapshot 形状。
2. 输入桥接删壳。
   从 [packages/runtime-vapor/src/runtime/bridge/input.rs](../../packages/runtime-vapor/src/runtime/bridge/input.rs)、[packages/runtime-vapor/src/runtime/bridge/create_element.rs](../../packages/runtime-vapor/src/runtime/bridge/create_element.rs)、[packages/runtime-vapor/src/runtime/bridge/mount.rs](../../packages/runtime-vapor/src/runtime/bridge/mount.rs)、[packages/runtime-vapor/src/runtime/vnode_helpers.rs](../../packages/runtime-vapor/src/runtime/vnode_helpers.rs) 和 [packages/runtime-vapor/src/runtime/transport.rs](../../packages/runtime-vapor/src/runtime/transport.rs) 删除 raw vnode-like 解析、compat child flatten、legacy raw element / raw array / raw function component 接受面。
3. 默认 transport 定契约。
   明确 vapor-only 下 [packages/runtime-vapor/src/runtime/transport.rs](../../packages/runtime-vapor/src/runtime/transport.rs) 与 [packages/runtime-vapor/src/runtime/real_dom/convert.rs](../../packages/runtime-vapor/src/runtime/real_dom/convert.rs) 之间的默认输入协议：要么保留 tagged handle 作为纯内部 transport，要么改成新的 shape；无论选哪种，都不能再把 compat createElement / raw vnode-like 语义混在默认主路径里。
4. real-dom 与 patch 删壳。
   删除 [packages/runtime-vapor/src/runtime/real_dom/compat_mount.rs](../../packages/runtime-vapor/src/runtime/real_dom/compat_mount.rs)、[packages/runtime-vapor/src/runtime/real_dom/compat_vapor_wrapper.rs](../../packages/runtime-vapor/src/runtime/real_dom/compat_vapor_wrapper.rs)、[packages/runtime-vapor/src/runtime/real_dom/element.rs](../../packages/runtime-vapor/src/runtime/real_dom/element.rs)、[packages/runtime-vapor/src/runtime/real_dom/fragment.rs](../../packages/runtime-vapor/src/runtime/real_dom/fragment.rs)、[packages/runtime-vapor/src/runtime/render_patch/compat.rs](../../packages/runtime-vapor/src/runtime/render_patch/compat.rs) 的 compat 调用链，让 core path 只处理 Text / Vapor / VaporWithSetup / Component。
5. 测试、构建与默认 feature 删壳。
   清理 [packages/runtime-vapor/tests](../../packages/runtime-vapor/tests) 下的 compat 专属测试文件，为每个被删除的 compat regression 补一份 vapor-only 等价测试，并把 [packages/runtime-vapor/Cargo.toml](../../packages/runtime-vapor/Cargo.toml) 的默认 feature 口径切到单模主干。

## 工作量判断

- 规模：Large
- 预估：约 5 到 7 个工作日
- 原因：修改面多，但已经被 Plan 11 压成少数明确边界；这阶段的难点主要是删分支后把类型和测试一并拉齐，而不是重新判断架构归属。

## 依赖与风险

- 这阶段不应同时重做 JS public API；否则会把 Rust 内核删壳和外层 contract 改写耦合在一起。
- 风险最高的是 [packages/runtime-vapor/src/runtime/types.rs](../../packages/runtime-vapor/src/runtime/types.rs)、[packages/runtime-vapor/src/runtime/types/mounted.rs](../../packages/runtime-vapor/src/runtime/types/mounted.rs)、[packages/runtime-vapor/src/runtime/transport.rs](../../packages/runtime-vapor/src/runtime/transport.rs) 与 [packages/runtime-vapor/src/runtime/render_patch/mod.rs](../../packages/runtime-vapor/src/runtime/render_patch/mod.rs) 的同改，因为它们共同决定了 mounted snapshot、默认 transport 与 patch root 的最终形状。

## 完成标准

1. [packages/runtime-vapor/src](../../packages/runtime-vapor/src) 下不再存在 `#[cfg(feature = "compat")]` 控制的 runtime 主路径，且 [packages/runtime-vapor/Cargo.toml](../../packages/runtime-vapor/Cargo.toml) 的默认 feature 也已切到单模口径。
2. [packages/runtime-vapor/src/runtime/types/mounted.rs](../../packages/runtime-vapor/src/runtime/types/mounted.rs) 不再保留 compat-only mounted state / patch kind / lifecycle kind。
3. runtime-vapor 的默认输入面只接受单模 vapor-only 主路径需要的 shape，不再接受历史 vnode-like / raw array / raw element / raw function component 输入。
4. [packages/runtime-vapor/tests](../../packages/runtime-vapor/tests) 下 compat 专属测试文件已删除或被改写为单模测试，并且对应 vapor-only regression 已补齐。
