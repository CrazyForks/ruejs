# text Blog SSR Demo

A small App Router blog built with `text`.

- Server-rendered index and post pages
- A route handler at `/api/posts`
- Client-side topic filtering and local likes
- A client todo app at `/todo`

```bash
pnpm --dir examples/text-blog-ssr dev
pnpm --dir examples/text-blog-ssr build
pnpm --dir examples/text-blog-ssr start
```
