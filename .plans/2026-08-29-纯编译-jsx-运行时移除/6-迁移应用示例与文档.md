## 上下文

- `RenderCounterDemo` 与 render-function 文档目前把 `h()` 当作显式边界；新契约不再支持这条路径，应改成解释编译产物、动态组件语法和 compiler-required 限制。
- 文档不能建议 `jsxImportSource`/automatic runtime；TypeScript 最终配置由任务 8统一为 `jsx: preserve`。

- 行为：站点/SSR 示例仍可构建运行，文档只展示编译 TSX 和支持的动态语法，搜索索引与源文档一致。
- 失败验证测试：先增加文档/应用源码负向搜索门禁，断言不存在 `h(`、`jsxImportSource` 和自动 runtime 安装说明。
- 失败验证命令：`rg -n '\bh\s*\(|jsxImportSource|jsx-runtime|jsx-dev-runtime' app docs --glob '!docs/search-index.json'`
- 预期失败原因：当前应用有 6 个手写调用文件，API/指南仍专门教授 `h()` 和 automatic JSX 配置。
- 通过验证命令：`pnpm run app-build && pnpm run docs-search-index && rg -n '\bh\s*\(|jsxImportSource|jsx-runtime|jsx-dev-runtime' app docs --glob '!docs/search-index.json'`
