## 上下文

- Shared 是无 Rue 内部依赖的基础包；Runtime 依赖 Shared 和已 ESM-only 的 Runtime Vapor，并有 7 个子入口需同步删除 CJS。

## 测试计划

- 行为：三个基础包仅发布 ESM JS 模块，Shared/Runtime 完整构建与 dry-run pack 无 CJS。
- 失败验证测试：`core-runtime-esm-package-contract.spec.ts` 覆盖 type、exports、buildOptions、ESM 解析和 pack 文件。
- 失败验证命令：`node scripts/build.js '^shared$' '^runtime$' && pnpm exec vitest run scripts/__tests__/core-runtime-esm-package-contract.spec.ts --project unit`
- 预期失败原因：Shared/Runtime 仍有 CJS 门面、require 条件、CJS 格式和打包文件。
- 通过验证命令：`node scripts/build.js '^shared$' '^runtime$' && pnpm exec vitest run scripts/__tests__/core-runtime-esm-package-contract.spec.ts scripts/__tests__/runtime-vapor-artifacts.spec.ts --project unit`
- 模拟策略：不使用 mock；使用真实构建、Node 解析和 npm dry-run pack。

## 步骤

1. 先写基础包 ESM 契约并确认失败。
2. 将 Shared/Runtime 声明为 `type: module`，把 `index.js` 改为直接转发各自 `*.esm-bundler.js` 的 ESM 门面。
3. 从根入口、Runtime 全部子入口和 `buildOptions` 移除 CJS，保留 browser/global 格式。
4. 更新 Runtime compiled 子路径断言，完整重建并运行契约测试。

## 验证

- 运行：`node scripts/build.js '^shared$' '^runtime$' && pnpm exec vitest run scripts/__tests__/core-runtime-esm-package-contract.spec.ts scripts/__tests__/runtime-vapor-artifacts.spec.ts --project unit`
- 预期：构建和测试退出 0，Shared/Runtime dist 与 pack 无 CJS，Runtime Vapor 契约保持 ESM。
- 所需证据：实施前失败、实施后通过计数、退出码 0 和三个包的 pack 列表。

## 完成
