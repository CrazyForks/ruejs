- 行为：根清单和 16 个 `@rue-js/*` 包都声明 Node `>=22.22.0`，Vite 工具包支持 7/8，根 TypeScript 使用 ES2022。

- 预期失败原因：多数包没有 Node engines，RSC/Vite 插件的 Vite peer 未收敛，tsconfig 仍为 ES2020。
- 通过验证命令：`pnpm exec vitest run scripts/__tests__/workspace-modern-baseline.spec.ts --project unit && pnpm check`
- 模拟策略：不使用 mock；直接读取实际工作区清单与 semver 范围。
