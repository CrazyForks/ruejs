## 上下文

- identity 索引不得延长 DOM 寿命，push、clear、compact、drain 和 unmount 后必须同步，命中后仍验证 `Object::is`。
- 当前 compact 阈值按固定 64 增长；即使 lookup O(1)，连续增长时总 compact visits 仍为平方级。

## 测试计划

- 行为：10k 原生 anchor/range 的 miss、hit 与 compact 总 entry visits 为线性上界；陈旧索引、清空、drain 后正确；非 DOM adapter 线性等价 fallback 不变。
- 失败验证测试：`native_anchor_range_total_lookup_and_compact_visits_stay_linear`。
- 失败验证命令：`pnpm --filter @rue-js/runtime-vapor test -- native_anchor_range_total_lookup_and_compact_visits_stay_linear`
- 预期失败原因：Vec lookup 扫描且固定步长 compact 都会使总 entry visits 超过线性上界。
- 通过验证命令：`pnpm --filter @rue-js/runtime-vapor test`
- 模拟策略：真实 `JsValue` 对象与现有 adapter；仅使用 test/dev 计数器统计 lookup 和 compact visits。

## 步骤

1. 添加 identity miss/hit、陈旧索引、compact、clear、drain 和非 DOM fallback 红测。
2. 为 anchor/range 增加基于 JS `WeakMap` 或等价弱身份机制的对象索引，不延长 DOM 生命，原生 identity miss 直接返回。
3. 在所有 Vec 重建、取空、保留和清理路径同步或重建索引，命中后校验 index 指向的 entry。
4. 将 compact 改为几何阈值或基于 stale 比例的触发，确保连续增长总 visits 近线性。
5. 单独验证 containment drain 不被身份索引错误取代；该路径由后续传递所有权移出复杂列表主路径。

## 验证

- 运行：`pnpm --filter @rue-js/runtime-vapor test`
- 预期：退出码 0；10k 原生路径 lookup + compact 总 visits 符合线性上界，非 DOM fallback 与生命周期回归通过。
- 所需证据：红灯总 visits、绿灯线性上界、compact 触发序列、陈旧索引恢复、非 DOM fallback 和完整退出码。
