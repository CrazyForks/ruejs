目的：让非列表及尚未迁移的保守路径用原生 DOM 身份索引定位 anchor/range，消除全局 Vec 逐项扫描。

## 上下文

- `find_anchor_index`/`find_range_index` 对原生 DOM 仍扫描 Vec；非 DOM adapter 依赖双向 `contains` 等价语义，必须保留 fallback。
- 身份索引只服务 Object identity 快速命中，不能成为行 owner 的替代；push、clear、compact、drain 和 unmount 后都要同步，命中后仍校验 `Object::is`。

## 测试计划

- 行为：10k 个不同原生 anchor/range 的首次 miss 与后续 hit 只产生线性候选校验；压缩、清空、陈旧索引后仍正确；非 DOM 等价 fallback 不变。
- 失败验证测试：新增 `native_anchor_and_range_lookup_counts_stay_linear` 与 `identity_indexes_recover_after_compaction_and_clear`。
- 失败验证命令：`pnpm --filter @rue-js/runtime-vapor test -- native_anchor_and_range_lookup_counts_stay_linear`
- 预期失败原因：当前每个新节点遍历已有 Vec，10k 首次挂载产生平方级候选比较。
- 通过验证命令：`pnpm --filter @rue-js/runtime-vapor test`
- 模拟策略：使用真实 `JsValue` 对象和现有 adapter；只通过测试计数器观察候选校验，不 mock lookup。

## 步骤

1. 添加原生 identity miss/hit、陈旧索引、压缩/清空及非 DOM fallback 红测。
2. 为 anchor/range 增加不延长 DOM 生命周期的对象身份索引，并在命中后验证 Vec entry。
3. 在新增、压缩、清空、drain 与 unmount 路径同步或重建索引。
4. 原生 identity miss 直接返回；只对没有原生对象身份语义的 adapter 执行线性等价 fallback。
5. 运行完整 runtime-vapor Wasm 测试并审查索引生命周期。

## 验证

- 运行：`pnpm --filter @rue-js/runtime-vapor test`
- 预期：退出码 0；10k 原生候选校验 O(n)，compact/range/anchor/lifecycle 测试全绿。
- 所需证据：红灯平方计数、绿灯线性上界、非 DOM fallback、索引清理断言、完整测试数量与退出码。

## 完成

完成时全局 anchor/range 保守路径拥有均摊 O(1) 原生身份定位，但复杂列表的主要验收仍要求使用行 owner 直接持有 mounted handle。
