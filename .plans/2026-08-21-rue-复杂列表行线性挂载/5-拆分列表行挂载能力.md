状态：未开始

## 上下文

- 多个布尔值容易产生无效组合；应使用可检查的行挂载模式和独立 capability，例如 direct leaf、owned structural 与 global fallback。
- `String/Number/Boolean` 只有在确认指向未遮蔽的全局构造器时才是标量化。

## 测试计划

- 行为：spread 与未遮蔽标量调用直挂但保留必要 watcher；参数、局部变量和 import 遮蔽的同名调用、ref、JSX 条件、组件和 opaque 调用均不误入 leaf。
- 失败验证测试：`complex_list_rows.rs::leaf_spread_and_unshadowed_scalar_calls_direct_mount`。
- 失败验证命令：`cargo test --manifest-path packages/swc-plugin-rue/Cargo.toml --test complex_list_rows leaf_spread_and_unshadowed_scalar_calls_direct_mount -- --exact`
- 预期失败原因：当前直挂与 effect 合并共用判定，且尚无同名绑定遮蔽防护。
- 通过验证命令：`cargo test --manifest-path packages/swc-plugin-rue/Cargo.toml --test complex_list_rows && pnpm exec vitest run --project unit-jsdom packages/runtime/__tests__/complexListRows.performance.spec.tsx`
- 模拟策略：真实 SWC 输出与 jsdom，不 mock watcher。

## 步骤

1. 添加 spread、未遮蔽标量调用、三类同名遮蔽和复杂行负例红测。
2. 定义可检查的行挂载模式，将直接挂载、批量构建、effect 合并和需要 owned mount 分开。
3. 对可直挂但不可合并的 spread/标量行保留 watcher，并由行 owner scope 持有。
4. 使用作用域感知绑定分析识别全局标量构造器；无法证明时回退 opaque。
5. 将 index 响应式跟踪收紧为作用域感知的实际使用，并保留闭包/别名使用的正例。

- 预期：退出码 0；spread/标量行快路径正确，同名遮蔽和其它复杂行保守，watcher 与属性删除语义不变。
- 所需证据：codegen 红转绿、capability 模式断言、遮蔽负例、watcher/调用次数和完整 SWC 退出码。

## 完成

完成时 SWC 以明确能力模式选择 leaf/owned/fallback 路径，不因 effect 无法合并而失去直挂能力。
