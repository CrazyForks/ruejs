# 任务 2: 编译器识别安全选中类名

批次：【批次 2】 依赖批次 1

状态：未开始

目的：让严格匹配的 keyed 单根行改用共享类名 controller，并让所有不支持表达式继续生成原来的逐行 effect。

来源任务：无

预计会话范围：只增加一个窄 AST 提取器及 keyed list 接线和编译器测试；不扩展到 style、文本、嵌套节点、非 keyed 或通用 patch 指令。

## 文件

- 修改：`packages/swc-plugin-rue/src/element_list.rs`
- 修改：`packages/swc-plugin-rue/src/vapor/mod.rs`
- 修改：`packages/swc-plugin-rue/src/element_list_tests.rs`
- 测试：`packages/runtime/__tests__/jsFrameworkBenchmark.list-performance.spec.tsx`

## 上下文

- `try_build_list_from_map` 在安全单根行生成 `child_body` 后调用 `coalesce_list_row_binding_effects`；可在此之前检查根 `className` 的生成 AST。
- 提取器只接受 `row.id === selected.get() ? "danger" : ""` 或左右互换，且比较左侧必须与该行显式 key 表达式结构等价。
- 成功提取时把逐行 class effect 改成一次非选中字符串 setter，并在列表外创建 controller；失败时返回 `None` 且不改 `child_body`。

## 测试计划

- 行为：精确模式输出一个 `_$vaporKeyedClassEffect`、一个列表 `onCommit` 和零个逐行动态 class effect；相近但不安全的模式输出必须与当前回退一致。
- 失败验证测试：在 `element_list_tests.rs` 新增 `extracts_safe_keyed_selected_class_effect` 与 `preserves_unsupported_keyed_class_effects`。
- 失败验证命令：`cargo test --manifest-path packages/swc-plugin-rue/Cargo.toml keyed_selected_class -- --nocapture`
- 预期失败原因：当前编译结果只会在每个 `renderItem` 中生成 `watchEffect(() => _$setClassName(...))`，没有共享 helper 或 `onCommit`。
- 通过验证命令：`cargo test --manifest-path packages/swc-plugin-rue/Cargo.toml keyed_selected_class -- --nocapture && cargo test --manifest-path packages/swc-plugin-rue/Cargo.toml element_list -- --nocapture`
- 模拟策略：使用真实 SWC parser、transform 和 codegen；通过编译产物与运行时集成测试验证，不 mock AST 节点。

## 步骤

1. 添加正向与负向编译测试；负向至少覆盖动态分支、非 `.get()`、`!==`、key 表达式不一致、嵌套 class 目标、非 keyed 和多根行。
2. 运行失败验证，确认正向用例因缺少共享 helper 失败，负向用例固定当前输出。
3. 在 `vapor/mod.rs` 增加局部 AST 提取函数：先完整验证候选，再一次性重写对应语句，禁止验证过程中部分修改 AST。
4. 在 `element_list.rs` 仅对安全单根、direct-root、显式 keyed 行调用提取器；成功时生成一个 controller，并把 `controller.sync` 作为 `vaporKeyedList` 的 `onCommit`。
5. 保证 controller 在结构 `watchEffect` 外只创建一次；列表重复执行不得重复注册选中 effect。
6. 运行编译器定向/周边测试，重建测试产物并运行 native-signal benchmark 语义测试，最后执行 Rust 格式检查与 `git diff --check`。

## 验证

- 运行：`cargo fmt --manifest-path packages/swc-plugin-rue/Cargo.toml -- --check && cargo test --manifest-path packages/swc-plugin-rue/Cargo.toml element_list -- --nocapture && pnpm run prepare-unit-test-artifacts && pnpm vitest run --project unit-jsdom packages/runtime/__tests__/jsFrameworkBenchmark.list-performance.spec.tsx`
- 预期：正向产物只有一个共享 controller，负向产物继续包含原逐行 class effect；选择、替换、删除、清空和再次创建列表的 DOM 语义不变。
- 所需证据：正向失败测试由红转绿、所有负向回退断言通过、编译器和运行时定向测试退出码 0、格式与空白检查通过。

## 完成

`packages/swc-plugin-rue/src/element_list.rs` 只对已证明安全的 keyed 选中类名模式接入 `_$vaporKeyedClassEffect`；所有范围外表达式保持原代码生成。
